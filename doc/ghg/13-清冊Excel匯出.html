清冊 Excel 匯出

所屬模組：application / adapter-rest
核心類別：EmissionInventoryService.java、TotalInventoryService.java
最後更新：2026-04-22

1. 功能簡述

清冊 Excel 匯出是 GHG 碳盤查的最終產出，可依據指定年度、據點、GWP 版本、協定類型（ISO / GHG Protocol）匯出 Excel Zip 壓縮檔，內含：

  • 單據點清冊：每個據點各產出一份完整的 Excel，包含基本資訊、盤查結果、各 Scope 排放數據、重大性評估、數據品質、不確定性等工作表

  • 彙總版清冊：跨據點彙整 CO2 排放量與活動數據，以一份 Excel 呈現所有據點的比較概覽

4.1 單據點清冊產製流程

xxxxxxxxxx
EmissionInventoryService.export(siteIds, companyId, arVersion, startDate, endDate, locale, protocolType)
  │
  ├─ 共用資料準備
  │   ├─ 設定語系 (LocaleContextHolder)
  │   ├─ 取得 GWP 值清單 (IpccArService)
  │   ├─ 取得據點資訊 Map (ISiteClient)
  │   ├─ 取得公司名稱 (ICompanyClient)
  │   ├─ 取得範疇樹 (ScopeService) → 依 protocolType 過濾
  │   ├─ 取得父範疇對應 Map (ScopeService)
  │   ├─ 取得單位換算率 Map (UnitExchangeService)
  │   ├─ 取得 IPCC 版本資訊
  │   ├─ 取得冷媒逸散率列表 (RefrigerantEquipTypeService)
  │   ├─ 取得重大性評估準則 (ImportanceService)
  │   └─ 取得重大性評估資料 (ImportanceService)
  │
  ├─ By 所有據點取得排放源列表 (EmissionSourceService)
  │   → groupingBy siteId
  │
  └─ 迴圈各 siteId 產製單據點 Excel
      ├─ 取得排放源資料，依範疇樹重新整理為 ExcelScopeEmissionDto
      ├─ 計算 CO2 排放當量 (GhgEmissionsCalculator.getCo2EmissionLevel)
      │   ├─ 一般計算（預設排除蒙特婁）
      │   └─ 包含蒙特婁計算（isIncludeMontrealProtocol = true）
      ├─ 組裝盤查結果 BO (DataInventoryResultHelpers)
      ├─ 取得數據品質分數 Map (EmissionSourceQualityService)
      ├─ 取得不確定性分析資料 (UncertaintyService)
      ├─ 組裝 GhgInventoryDetailBO (DataInventoryDetailHelpers)
      ├─ 設定數據品質等級評分 (QualityService)
      ├─ 產生基本資訊 BO (DataEmissionInventoryUtils)
      └─ 呼叫 ExportInventoryExcelUtils.export() 產生 Excel byte[]

10. 擴充指引

新增清冊 Excel 工作表

  1. 建立對應的 EmissionInventoryExcelXXXHelpers 類別，實作 setXXXSheet(Sheet sheet, ...) 方法

  2. 在 ExportInventoryExcelUtils.export() 依序建立 Sheet、設定 Sheet 名稱、呼叫 Helper

  3. 在 GhgInventoryDetailBO 新增對應資料欄位

  4. 在 DataInventoryDetailHelpers.genInventoryDataDetail() 補上資料組裝邏輯

  5. 在 i18n properties 新增 Sheet 名稱對應的 message key

新增協定類型（如新標準）

  1. 在 ProtocolType enum 新增類型

  2. 在 ExportInventoryExcelUtils.export() 補上 protocolType 判斷分支

  3. 在 ScopeService 確認新協定類型的範疇樹資料存在

  4. 新增對應的 i18n key

調整彙總版欄位

  1. 修改 SummarySiteDto 欄位定義

  2. 在 TotalInventoryService.getSummarySiteDTOsActData() 補上資料裝填邏輯

  3. 在 ExportTotalInventoryExcelUtiles 補上對應的 Excel 儲存格設定

11. 交接建議（維運重點）

  • 單據點清冊與彙總版的匯出同屬一支 API（/api/v2/emission-inventory/export），最終打包成同一個 Zip 下載

  • 清冊 Excel 的工作表順序有明確的依賴關係（例如 Scope 2-6 需先計算，因為 Scope 1 的某些欄位會參照 Scope 2 總和），調整時需特別留意

  • 協定類型（ISO / GHG） 會影響工作表數量與 Sheet Helper 的呼叫邏輯，兩個版本需分別維護

  • 重大性評估篩選（filterImportanceEmissionSourceWithActivityDatas）只有 ISO 版本會執行，GHG Protocol 版本使用全數排放源計算

  • 彙總版公司名稱目前是以前端傳入的 companyName 統一覆蓋，若未來要改為各據點關聯的公司名稱，需移除 TotalInventoryService 中的覆蓋邏輯

  • 匯出相關 log 較少，若遇到問題難以定位，建議在各 setXXXSheet() 入口補上 log 後再排查
