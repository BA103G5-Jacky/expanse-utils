## 四、設定使用者變數

按下鍵盤上的 **Win + R** 鍵，打開「執行」對話框。

輸入以下指令並按 Enter：

```
rundll32.exe sysdm.cpl,EditEnvironmentVariables
```

這會直接跳過系統設定頁面，幫你打開「環境變數」的小視窗。

**目前已設定環境變是 C:\Users\ethan.yp.hsu\DevTool**
後續可以直接把指令集放到這個路徑下，即可於 Terminal 使用

## 七、k8s 環境

### Step 1｜申請本機 Admin 權限 🔐

- 申請連結：[https://dgoa.deltaww.com/SmartFormV3/#/?Type=INFRA&SubType=070](https://dgoa.deltaww.com/SmartFormV3/#/?Type=INFRA&SubType=070)
- 申請內容參考：`申請 Admin 權限.png`
- 開始時間：T+3 日，申請期限：7 天

---

### Step 2｜事先下載所需安裝檔

> 可在取得 Admin 權限前先把檔案下載好

- Ubuntu AppxBundle（離線安裝用）
- WSL2 Linux Kernel Update 套件 (msi)（**必要**，公司環境 `wsl --update --web-download` 無法使用）
- Rancher Desktop (msi)

> 參考文章：
> - [WSL 安裝指南](https://learn.microsoft.com/zh-tw/windows/wsl/install)
> - [WSL 手動安裝步驟](https://learn.microsoft.com/zh-tw/windows/wsl/install-manual)

---

### Step 3｜取得 Admin 權限後：安裝 WSL2

> 以下指令需以系統管理員身份執行

**啟用 WSL 功能：**

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
```

**啟用虛擬機器平台功能：**

```powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

> ⚠️ 執行完以上兩個指令後，需**重新開機**才能繼續後續步驟。

**重開機後，安裝 WSL2 Linux Kernel Update：**

> ⚠️ `wsl --update --web-download` 在公司環境中**無法使用**，必須改用 WSL2 Linux Kernel Update msi 安裝包。

執行事先下載好的 **WSL2 Linux Kernel Update msi** 進行安裝。

安裝完成後，設定 WSL 預設版本為 2：

```powershell
wsl --set-default-version 2
```

---

### Step 4｜安裝 Ubuntu

1. 執行下載好的 Ubuntu AppxBundle 進行安裝
2. 安裝完成後開啟 Ubuntu，依提示**設定使用者帳號與密碼**
3. 確認 WSL 版本為 2：

```powershell
wsl -l -v
```

---

### Step 5｜安裝 Rancher Desktop

1. 執行 Rancher Desktop msi 進行安裝（🔐 需 Admin 權限）
2. 安裝後開啟，Container Runtime 選擇 **`dockerd (moby)`**
3. 確認 Kubernetes 版本與叢集設定是否正確
4. 後續依照 Step 6 設定 Docker insecure registry，以及 Step 7 設定 kubeconfig

---

### Step 6｜設定 Rancher Desktop Docker 存取內部 Image Registry

若不設定此檔案，拉取公司內部 registry 的 image 會被擋掉。

編輯 Rancher Desktop 內建 Docker 的 daemon 設定檔：

- **路徑：** `\\wsl.localhost\rancher-desktop\etc\docker\daemon.json`

將內容改為：

```json
{
  "insecure-registries": [
    "artifact.deltaww.com:8446",
    "10.136.219.58:5000"
  ]
}
```

> 注意：這裡修改的是 Rancher Desktop 裡面的 Docker daemon 設定，不是 WSL2 Ubuntu 本身的 `/etc/docker/daemon.json`。

---

### Step 7｜設定 kubeconfig

kubeconfig 路徑：`C:\Users\ethan.yp.hsu\.kube\config`

將以下內容寫入（或覆蓋）該檔案：

```yaml
apiVersion: v1
kind: Config
clusters:
  - name: itdc-cloud-dev
    cluster:
      server: https://itdcrp.deltaww.com/k8s/clusters/c-m-r58b7c59
      insecure-skip-tls-verify: false
  - name: itdc-cloud-prod
    cluster:
      server: https://itdcrp.deltaww.com/k8s/clusters/c-m-9cxxggvv
      insecure-skip-tls-verify: false
users:
  - name: itdc-cloud-dev
    user:
      token: kubeconfig-u-fgjcw574nfdsdqn:5g2qf544lj4jd8p26vwtsnz4pfvptkxb9bzn6cvpnml47pz8shjpcv
  - name: itdc-cloud-prod
    user:
      token: kubeconfig-u-fgjcw574nf86fcl:xv5f2f8d59l96t287xrqbb2k7t7txc7g7rjrk8bgbhljxgl5rcw7wv
contexts:
  - name: itdc-cloud-dev
    context:
      cluster: itdc-cloud-dev
      name: itdc-cloud-dev
      user: itdc-cloud-dev
      namespace: dsp
  - name: itdc-cloud-prod
    context:
      cluster: itdc-cloud-prod
      name: itdc-cloud-prod
      user: itdc-cloud-prod
      namespace: dsp
preferences: {}
current-context: itdc-cloud-dev
```

> ⚠️ token 有時效性，若失效需重新從 Rancher 平台取得並更新。
