## 1. 解釋 ipcc_ar 表格名稱取名原因
   - `ipcc_ar` 即為 **IPCC Assessment Report** 縮寫，因考量會直接存放 IPCC 原始資料數據，故取其名，而不採用原預想之 `gwp_ipcc_coef` **GWP IPCC 係數** ，如此應較符合裝載原始資料之目的。

   1. [2024-07-08] 有被詢問一氫氟化物混合物(HFCs) **R-449a** 的 **GWP-100** 數值，原預想可查表 IPCC 直接找到相對應之 GWP-100 數值，但實際深究發現無法直接查詢到對應之項目，而其實它為四種 **氫氟化物** 按照比率加總起來的混合物，計算公式如下:

        |氫氟化物混合物(HFCs)|GWP-100||比率(總和 1)||
        |--|--|--|--|--|
        |R-449a = |||||
        |R-32|771|X|0.243|+|
        |R-125|3740|X|0.247|+|
        |R-1234yf|0.501|X|0.253|+|
        |R-134a|1530|X|0.257||
        |||||= 1504.469 GWP-100|

       **R-449a** = (R-32) **771** x **0.243** + (R-125) **3740** x **0.247** + (R-1234yf) **0.501** x **0.253** + (R-134a) **1530** x **0.257** = **1504.469 GWP**

   2. 題外知識，**R** 為冷媒之縮寫 **Refrigerant**，而 **HFC-134a** 和 **R-134a** 是同一物質嗎?<br>
   有說法說明只是的兩種不同命名方式，前者是**化學分子表達**，後者是**英文冷媒型號**的簡寫。在冷凍產業中，為了簡便，通常直接稱之為 **R-134a**。<br>
   但也有文章說明是接近的東西，是有一點點不一樣。[Is HFC134a the same as R134a | Core Differences and Applications](https://www.echemi.com/cms/1417912.html)<br>
