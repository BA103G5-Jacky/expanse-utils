排放源與活動數據 Excel 匯入

所屬模組：adapter-rest / application 最後更新：2026-04-27

1. 功能簡述

此功能提供使用者透過 Excel 範本批量匯入排放源與活動數據，取代手動逐筆新增的作業方式：

  • 排放源 Excel 匯入：批次新增多個排放源（含 Extension 欄位）

  • 活動數據 Excel 匯入：批次新增活動數據（含 Extension 欄位、計算法別驗證）

  • 範本下載：依據據點 / 年度動態產生含下拉選項的 Excel 範本

  • 欄位驗證：必填欄位檢核、下拉選項合法性驗證、日期區間驗證、計算方法學驗證

  • 錯誤回饋：匯入前先完成全部驗證，有錯誤則回傳明細清單（Sheet 名稱、行號、錯誤欄位）

  • 匯入紀錄：每次匯入皆建立 import_data_log 紀錄執行狀態與結果

10. 常見問題與注意事項

Q1：匯入時驗證有錯誤，資料會被寫入嗎？

不會。系統在 parseExcel() 完成後先檢查 validationResult.hasError()，有任何一筆錯誤即整批拒絕，不執行寫入。

Q2：為何活動數據範本需要帶入 siteId / annual？

因為 排放源下拉清單 是依據「據點 + 年度」動態查詢，確保使用者只能選擇該據點該年度已存在的排放源。

Q3：活動數據匯入後，CO2 排放量是如何更新的？

匯入完成後，CompanySiteCo2EmissionService.resetSiteCo2EmissionSummary() 會非同步重新計算該批排放源關聯的據點 CO2 排放當量，不會阻塞匯入 API 的回應。

Q4：ISO Protocol 欄位在 Excel 中的格式是什麼？

Excel 中顯示格式為 "1.1: 固定燃燒直接排放"，系統會擷取 : 前的數字部分（如 1.1）做比對驗證。

Q5：如何新增新的 Sheet 類別支援？

  1. 在 ActivityDataImportConstants.SheetIndex 新增 Sheet Index 常數

  2. 在 ActivityDataImportService 新增對應 parseXxxSheet() 方法

  3. 在各 Validation Rule 的 switch 新增對應的 case

  4. 更新 Excel 範本檔案（ghg_activity_data_import_template.xlsx）

  5. 更新 ActivityDataImportConverter 的轉換邏輯
