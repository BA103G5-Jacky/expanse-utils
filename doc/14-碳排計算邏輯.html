1. 功能簡述

碳排計算是 GHG 碳盤查的核心運算模組，負責將活動數據透過排放係數與 GWP 值，計算出各 Scope / 類別的溫室氣體排放量：

  • 七大溫室氣體排放量計算（未乘 GWP）：CO2、CH4、N2O、HFCs、PFCs、SF6、NF3

  • CO2 排放當量計算（kgCO2e）：排放量 × GWP 值加總

  • 活動數據單位轉換：依 Scope 類別與係數單位進行對應轉換

  • ISO 2.1 電力排放特殊計算：Location Based / Market Based 分開處理

  • 逸散排放特殊計算（1.3 / 1.4）：填充量法、冷媒逸散率、氣體濃度因子

  • 生質 CO2 排放計算（1.1 / 1.2）：生質碳排另計，不加入總碳排

  • 蒙特婁協定氣體排除機制（1.3 / 1.4）：可依參數決定是否納入管制氣體

4.3 核心計算公式

xxxxxxxxxx
CO2 排放當量（kgCO2e）= 活動數據 × Σ(排放係數ᵢ × GWPᵢ)


其中：
  排放係數ᵢ = 原始排放係數 × 係數單位換算率
  GWPᵢ      = 由 IPCC 評估報告取得的各氣體暖化潛勢值
  i         = CO2, CH4, N2O, HFCs, PFCs, SF6, NF3（依類別使用不同組合）

5.2 特殊計算情境

ISO 1.3 / 1.4 — 填充量法（非排放係數法）

  • 觸發條件：EmissionSourceUtils.isNeedAssignCoef() 為 false

  • 計算方式：

xxxxxxxxxx
1.3 填充量法：
  actData（kg） × GWP（對應冷媒氣體） = CO2 排放當量


1.4 冷媒逸散率法：
  actData × 逸散率（%/100） × 單位換算到 kg × GWP（對應冷媒氣體）= CO2 排放當量
  逸散率預設值：100%（若 extension 未填寫）

  • 氣體種類：從 EmissionSourceExtensionType.REFRIGERANT_TYPE 取得

  • 蒙特婁協定排除：若 isIncludeMontrealProtocol = false，且氣體為管制氣體則略過

ISO 1.3 — 氣體濃度因子（convertActivityDataToTargetUnit）

  • 僅適用 1.3

  • 從 ActivityDataExtensionType.GAS_CONCENTRATION 取得，為百分比數值（需除以 100）

  • 計算公式：actData × 氣體濃度因子 × 單位換算率

ISO 1.1 / 1.2 — 生質 CO2 排放

  • 觸發條件：排放係數含生質 CO2 欄位（efRecomBioCo2）

  • 計算方式：co2EmisLvlBoHelper.handleBioCo2EmissionCase() 另計，且將主要係數的 CO2 設為 0，避免重複計入總排放

ISO 3.4 — 不加入 GHG Protocol 累加

  • scopeAllGhgToCo2Setter(co2EmissionLevelBo, actData, ghgCoefValuesBo, gwpValuesBo, true) 第五個參數 true 表示略過 GHG Protocol 欄位累加

  • 適用 Scope：1.3（填充量法）、1.4（冷媒逸散率法）

  • 判斷方式：EmissionSourceUtils.isMontrealProtocol(esWithAdDto, ipccArDtoList)

  • 使用場景：清冊報告中，蒙特婁協定管制氣體需另外列表，不計入 GHG 總排放量

10. 交接建議（維運重點）

  • 計算器是「純計算」服務，不做任何 DB 操作，資料準備與後處理由呼叫端負責

  • 任何計算問題排查，第一步先看 log 中 GhgEmissionsCalculator ... error 的訊息，通常是係數未指定或活動數據未正確填寫

  • ISO 2.1 電力是唯一不走 switch-case 累加的 Scope，邏輯完全在 ISO21Helper，排查 2.1 異常時請直接看該 class

  • 蒙特婁協定氣體（1.3 / 1.4 填充量法情境）預設被排除，若清冊需要納入，呼叫時需明確傳 isIncludeMontrealProtocol = true

  • 生質 CO2（1.1 / 1.2）不會加入總碳排，而是獨立累加，確保報表數字加總正確

  • 單位轉換失敗不會 silent fail，會直接拋 GeneralDspException，上層需做好例外處理
